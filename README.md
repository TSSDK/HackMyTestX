# MyTestX-Crack
Создает копию теста в котором любой не пропущенный ответ будет правильным.


Кидаете exe и bat в 1 папку с exe файлом теста и копируете его название. Открываете bat вставляете название теста в строку в виде "название теста.exe" без кавычек. Следующую строку просто  Enter и он создаст кряк копию

TSSDK, CatFish и ИИ агенты виновны в создании скрипта

ВАЖНО скрипт по своей сути заменяет байты программы в +- 6 местах и по этому если тесты связаны не с локальным сервером возможно ничего не заработает но проверьте и дайте знать
